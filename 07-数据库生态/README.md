# 第七阶段：数据库生态全貌

> 目标：了解非关系型数据库，知道什么场景用什么库
> 时间：穿插进行，每周 1-2 小时
> 建议开始时间：
>   - Redis：第 4 周后
>   - MongoDB：第 8 周后
>   - Elasticsearch：第 10 周后

## 内容

| 数据库 | 类型 | 核心场景 |
|--------|------|---------|
| Redis | 键值型 | 缓存、计数器、分布式锁 |
| MongoDB | 文档型 | 灵活 Schema、JSON 存储 |
| Elasticsearch | 搜索引擎 | 全文搜索、日志分析 |
