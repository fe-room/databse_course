# 数据库中级后端学习课程

> 前端工程师转后端，3-6 个月业余学习路线

## 如何使用本课程

```
每个阶段目录结构：
  phase-name/
    └── week-name/
        ├── README.md  ← 本周详细学习内容 + 练习
        ├── exercises/ ← 练习模板 / 初始代码
        └── solutions/ ← 参考答案（先自己写再看）
```

**学习流程：**
1. 打开当前周的 `README.md`，按 Day 顺序学习
2. 在 `exercises/` 里完成练习
3. 完成后对照 `solutions/` 检查
4. 进入下一周

---

## 课程总览

| 阶段 | 周次 | 主题 | 产出物 |
|------|------|------|--------|
| 1 | 第 1 周 | SQL 基础强化 | 常用查询语法掌握 |
| 1 | 第 2 周 | 窗口函数与 CTE | SQL 查询工具箱 CLI |
| 2 | 第 3 周 | 表设计与数据类型 | 博客系统建表 |
| 2 | 第 4 周 | 后端连接数据库 | 博客系统 REST API |
| 3 | 第 5 周 | ER 建模与范式 | 电商 ER 图 |
| 3 | 第 6 周 | 电商系统设计 | 完整电商 DDL + 下单事务 |
| 4 | 第 7 周 | 索引原理 | 索引分析与对比 |
| 4 | 第 8 周 | 慢查询优化 | 优化报告 |
| 5 | 第 9 周 | 事务基础 | 隔离级别实测 |
| 5 | 第 10 周 | 锁与死锁 | 死锁分析报告 |
| 6 | 第 11 周 | 备份恢复 | 自动备份脚本 |
| 6 | 第 12 周 | 主从复制 + 连接池 | Docker 主从 + 读写分离 |
| 7 | 穿插 | Redis / MongoDB / ES | 基础知识 + 简单接入 |

---

## 推荐学习顺序

1. 按编号顺序学习（01 → 07）
2. Redis 可在第 4 周后开始穿插
3. MongoDB 可在第 8 周后开始穿插
4. 每阶段结束必须有产出物再进入下一阶段

---

## 环境要求

- MySQL 8.0+（推荐 Docker）
- DBeaver 或任意 MySQL GUI
- Docker Desktop（第 12 周需要）
- 熟悉一种后端语言（Node / Python / Go）
